## 协作纪律

1. 一单一事：每个模板只做一件事，Codex 不得顺手重构其他模块；接口（函数签名）以交接包为准，改接口必须先在交接包里声明。
2. 验收不过不进下一单：尤其 T1.2 三件套（M1）和 T2.2 的 0 漏怪可达性结论，直接决定周五锁 A 还是转 B。
3. 数字只认仿真：解析模型给的伤害是上限，任何"漏怪数"结论必须出自 simulate.py。
4. 运行时间必报：讲座明确要求论文报告代码运行时间，每单交接包都要有。
5. AI 使用留痕：每次派单与验收结果记一笔（日期＋模板编号＋结论），赛后写「AI 工具使用详情.pdf」时直接取用；进论文的文字与结论必须经队员理解复核后重写。
