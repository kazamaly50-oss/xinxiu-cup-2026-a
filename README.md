# 2026 新秀杯 A 题 · 三人协作

## 协作纪律

1. 一单一事：每个模板只做一件事，Codex 不得顺手重构其他模块；接口（函数签名）以交接包为准，改接口必须先在交接包里声明。
2. 验收不过不进下一单：尤其 T1.2 三件套（M1）和 T2.2 的 0 漏怪可达性结论，直接决定周五锁 A 还是转 B。
3. 数字只认仿真：解析模型给的伤害是上限，任何"漏怪数"结论必须出自 simulate.py。
4. 运行时间必报：讲座明确要求论文报告代码运行时间，每单交接包都要有。
5. AI 使用留痕：每次派单与验收结果记一笔（日期＋模板编号＋结论），赛后写「AI 工具使用详情.pdf」时直接取用；进论文的文字与结论必须经队员理解复核后重写。

本仓库用于「守关：塔防游戏中的防御布局与资源调度」队内协作。2026 年 11 月 25 日晚集中启动，以下日期和同步时间均为北京时间。分工依据队伍 11/24 提供的《A题-三方分工表》及随后确认，周五验收范围为 M1 和 A1 的 0 漏怪可达性。

## 三岗责任与工具

- **队长兼编程手**负责派单、运行、验收、选题决定和最终提交。使用 Codex 按 T0.1–T6.2 逐单实现代码，交付代码和 JSON 交接包，按验收反馈修正。模型口径和函数签名按已确认的交接包执行。
- **建模队员**使用 Hermes 整理题意、假设、模型框架、公式推导、参考文献、灵敏度和检验方案，并复核相关产物。维护每日汇总、待决事项和 AI 使用台账。核心推导由队员手算或数值复核后交队长验收。[建模岗指令](modeling/AGENT.md)
- **论文队员**使用 WorkBuddy 搭建 Word 骨架、组织章节初稿、统一格式和整理附录，并核对结果来源、图表和正文。摘要、问题分析、结论由队员理解复核后重写，其余章节经通读改写后定稿。[论文岗指令](writing/AGENT.md)
- 三个岗位均由真人队员承担，各自复核 AI 产物，队长作最终验收。Muse 辅助规划和验收标准整理。封面按官方模板填写三名真实队员信息。
